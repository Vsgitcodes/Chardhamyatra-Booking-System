Auto Account Switching & Role Detection

MetaMask account changes are now detected instantly. When you switch between Admin, Provider, or Customer wallets the UI updates automatically — no refresh needed. Role is detected by comparing your address against the contract owner and provider list.

Live accountsChanged listener
Instant role switching (Admin / Provider / Customer)
Yellow notification on account switch
Disconnect button added

Multi-Role Dashboard

Unified interface now serves all three user roles inside a single page. Admin can create packages, Customers browse and book, Providers track services and withdraw earnings — all without navigating away.

Tab-based Admin / Customer / Provider panels
Provider balance card with live withdrawal
Real-time package status badges
v2.2 Fix
January 22, 2025

Package Data Parsing Fix

Resolved the "pkg is not iterable" error that prevented packages from loading on the customer view. Web3 returns contract call results as index-keyed objects, not arrays — the parser now handles both formats.

Fixed destructuring crash on getPackage()
Fixed getService() index access
Added fallback keys for all contract returns
Added console logging for every contract call
v2.1 Security
January 20, 2025

Network Validation & Chain Switch

The app now checks the active chain on every wallet connect. If you're on the wrong network, it prompts MetaMask to add or switch to Ganache Local automatically — no manual config required.

Auto wallet_switchEthereumChain on connect
wallet_addEthereumChain fallback for new installs
chainChanged listener reloads page
v2.0 Major Release
January 15, 2025

KedarnathBooking Smart Contract Launch

Full smart contract deployed on Ganache with all core flows: Admin package creation, Customer booking with ETH payment, multi-provider service tracking, and provider withdrawal. Six Ganache accounts mapped to roles.

addPackage() — admin creates packages with N services
bookPackage() — customer pays exact totalPrice in wei
markServiceComplete() — provider marks & earns
withdrawPayments() — provider pulls balance to wallet
6-account role mapping: Admin / Hotel / Taxi / Food / Meals / Customer
